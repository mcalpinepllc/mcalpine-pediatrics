## Accessibility and Quality Assurance

The reference build has one main heading, named landmarks, labeled form controls, descriptive image alternative text, visible keyboard focus, responsive mobile layouts, and reduced-motion support. Recheck these qualities after recreating the design in Squarespace because native blocks and custom CSS can change the final document structure.
