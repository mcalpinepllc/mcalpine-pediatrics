# Telehealth Link Verification

The client-supplied `http://www.doxy.me/v2/check-in/drmcalpine` address redirects to the canonical HTTPS page at **`https://doxy.me/v2/check-in/drmcalpine`**.

The loaded page title is **“Dr. McAlpine's Check In Page | Doxy.me.”** It displays Doxy.me branding, asks the visitor for a full name, and provides a **Check in** button so Dr. McAlpine can be notified that the patient is waiting. No information was entered or submitted during verification.

The practice website must therefore label this destination as **Doxy.me telehealth check-in**, not Doximity. The portal should open it as an external service in a new browser tab, disclose that the user is leaving the practice website, and avoid collecting symptoms, diagnoses, or medical history before the handoff.
